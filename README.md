# 💫 About Me:
Hi, I’m Anastasios Gratsakis. I hold a Bachelor’s degree in Philosophy and a Master’s degree in Neuroscience.<br><br>I am currently working with mice, performing in vivo electrophysiological recordings using Neuropixel 2.0 probe, and developing my skills in electrophysiological data analysis. I also conduct home-cage behavioral experiments using the open-source platform EthoPy.<br><br>My interests lie at the visual neuroscience, visual representations and visual mental imagery. I have experience with programming and scientific computing, including Python, Jupyter, Visual Studio Code, Matplotlib, Seaborn, DataJoint, MariaDB, DBeaver, Git/GitHub, and LaTeX.<br><br>I also have experience working with Raspberry Pi 4 for hardware-based projects and Blender for 3D modeling and visualization.
